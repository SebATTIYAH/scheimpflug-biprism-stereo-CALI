# Current limits and requirements for measured validation

- This is executable research code for a joint model. Center and reconstruction errors on synthetic images do not establish accuracy on a physical instrument.
- Raw images support geometric checks, but cannot identify unknown glass dispersion, PSF asymmetry, scattering, or prism manufacturing errors. Refractive index, wedge angles, thickness, board dimensions, and principal point are fixed by default; incorrect values can produce systematic bias.
- Dot-center refinement interpolates grayscale normal-gradient peaks and uses robust Sampson ellipse fitting. Interpolation, quantization, blur, and non-affine circle imaging can bias the center; the fit residual is not center accuracy. Covariance remains null unless the user supplies a validated estimate.
- Automatic ordering supports only complete, regular, symmetric circular grids and requires an orientation anchor. Missing dots, extra dots, and irregular patterns require manual CSV review. The first version has no native interactive GUI or mouse-based anchor selection; labeled overlays and CSV files provide the review path.
- The projected_circle/contour_review interface is implemented, but default optimization still uses centers. There is no model-dependent iteration to update centers; a lower residual from such feedback would not count as independent evidence of improved accuracy.
- The data Jacobian is a local numerical diagnostic sensitive to parameter scaling, thresholds, pose coverage, and noise. Full rank does not guarantee global uniqueness or mechanically credible estimates. Unverified small parameter standard deviations are not reported.
- In the first version, physical_constrained exports physical angles only under strict conditions; it does not optimize another freely varying set of mechanical parameters. Independently fixed Rp, pixel geometry, assembly sign, and passing diagnostics are all required. Export is rejected near zero sensor tilt.
- Invalid ray paths receive an exterior penalty with a fixed residual length. An initial guess far outside the feasible region may fail; adjust the known assembly initialization or ROI branch mapping. Failure does not demonstrate the absence of Scheimpflug tilt.
- The optional aperture bound is currently an x/y rectangle and is checked at both front and rear intersections. Complex finite apertures and occluding solids from CAD are not traced. Without a known aperture, only half-face and face-order checks are made.
- The radial inverse is guaranteed monotonic only within the configured radius_limit_mm domain. Points outside that field and nonmonotonic distortion models are rejected.
- Held-out board distances come from the same known calibration board and test internal consistency on unseen observations. Measured acceptance still requires an independent translation stage, gauge blocks, or a traceable 3D reference.
- DIC matching, strain, deep learning, and a web or large desktop GUI are not implemented. Converting ordinary color images to grayscale does not remove prism chromatic aberration.

For measured calibration, the user must supply original calibration images, board geometry and point-number orientation, ROI-to-physical-branch mapping, prism specifications and wavelength, magnification or an initial K, the source of the principal point, an initial prism pose, and any needed independent constraints. Missing inputs prevent measured calibration but do not affect the synthetic demonstration or unit tests.
